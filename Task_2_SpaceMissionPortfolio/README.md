# Task 2: Space Mission Investment Tracker

## Description
This program tracks investments in space mission assets. It calculates total investment and number of assets, then saves the summary to a CSV file.

## How to Run
1. Make sure Python is installed
2. Run: `python space_mission_portfolio.py`
3. Output will be shown in terminal and saved as `space_portfolio_summary.csv`

## Files
- `space_mission_portfolio.py` - Main program
- `space_portfolio_summary.csv` - Generated output after running
